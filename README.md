# 📚 Biblioteca Virtual - Blog Literário

Uma plataforma web interativa e inclusiva dedicada a entusiastas da leitura, onde os utilizadores podem descobrir novos títulos, partilhar opiniões e manter-se atualizados sobre o mundo editorial.

## ✨ Funcionalidades Principais

### 1. **Gestão de Opiniões (Posts)**
- **Publicação Dinâmica:** Formulário para adicionar título, autor, género, avaliação (1 a 5 estrelas) e opinião pessoal.
- **Persistência de Dados:** Integração com `localStorage` para que os seus posts fiquem guardados mesmo após fechar o navegador.
- **Interatividade:** Sistema de "Likes" em cada publicação.

### 2. **Filtros e Pesquisa**
- **Busca em Tempo Real:** Localize livros rapidamente por título ou autor através da barra de pesquisa.
- **Filtragem Avançada:** Organize a visualização por género literário ou por pontuação (estrelas).

### 3. **Destaques e Navegação Visual**
- **Destaques da Semana:** Secção que exibe automaticamente os livros com mais interações.
- **Carrossel Interativo:** Exibição visual das capas dos livros.
- **Efeito Flip Card:** Passe o rato sobre as capas para ler a sinopse no verso do cartão.

### 4. **Acessibilidade e Personalização**
- **Modo Escuro (Dark Mode):** Alternância de temas para maior conforto visual.
- **Widget de Acessibilidade:**
  - Ajuste dinâmico do tamanho do texto (aumentar/diminuir).
  - Modo de Alto Contraste para melhor leitura.
  - Atalhos de teclado (Alt + 1, 2 ou 3).
- **Design Responsivo:** Totalmente adaptado para telemóveis, tablets e computadores.

## 🚀 Tecnologias Utilizadas

O projeto utiliza tecnologias web modernas e leves:

* **HTML5** - Estrutura semântica.
* **CSS3** - Estilização personalizada, animações e variáveis de tema.
* **JavaScript (Vanilla)** - Lógica de filtros, persistência e manipulação do DOM.
* **Bootstrap 5** - Framework para layout responsivo e componentes UI.
* **Google Fonts** - Tipografias *Playfair Display* e *Lato*.
